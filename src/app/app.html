Questions

Does Hevy import Fitbod workouts?

Not directly. Hevy only imports CSV files in the Strong app's format. This converter turns Fitbod's WorkoutExport.csv into that format, so Hevy accepts it. Every workout, set, weight, rep, warm-up and note comes along.

How do I export my workouts from Fitbod?

In Fitbod open Log, tap ⋯ and choose Export Data. Fitbod sends WorkoutExport.csv. Save it to your phone or computer, then drop it here.

Is my workout data uploaded anywhere?

No. The file is read and converted by your browser. This page makes no network requests after it has loaded, has no analytics, and the converted file goes straight to your downloads.

Why is the weight per dumbbell, not per pair?

Fitbod stores the weight of one dumbbell plus a multiplier (2 for a pair) that it only uses for volume. Hevy logs the weight per dumbbell, so the converter writes the weight exactly as you logged it and ignores the multiplier.

Can I import into Hevy more than once?

Hevy allows one import per account. Check the receipt above first: the number of sets and workouts, the date range, and the exercises Hevy does not know (those are created as custom exercises).

Weights are written as logged (per dumbbell). Warm-up sets are marked as warm-ups. Fitbod exports no end time, so every workout gets an estimated 60 minutes.
